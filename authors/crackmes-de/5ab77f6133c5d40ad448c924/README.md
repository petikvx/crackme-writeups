## Prédicat (résumé)

1. Mot de passe **13** caractères `0-9` / `a-z` (upper → lower).
2. CRC bit-à-bit (poly `0xedb88320`, init BSS `0x3c817a05`) → dword clé.
3. Fork + pipe : le fils XOR le blob `.crypt` avec cette clé ; le père exécute le code clair.
4. Le clair contient `secret code: 62f6sHpFshNh844rTh`.

## Debug GDB (pas à pas)

ELF32 NASM **sans section headers**, entry **`0x8048245`**. Si `gdb file` râle : zéroter `e_shoff/e_shnum` sur une copie (souvent déjà à 0).

```bash
gdb -nx -q ./original/staple
(gdb) set debuginfod enabled off
(gdb) starti
(gdb) x/30i $eip
```

| Adresse | Rôle |
|---|---|
| `0x8048245` | entry (`nop` / frame) |
| `0x804825b` | alloc / setup |
| `0x8048274` | `call 0x8048134` — `read(0, …)` password |
| `0x8048134`…`0x8048145` | helper read : `mov eax,3` ; `int 0x80` |
| `0x8048287` | `call 0x8048188` — strlen |
| `0x804828c` | `cmp eax, 0xd` — **13** caractères |
| `0x8048295` | `call 0x804820a` — charset `0-9a-z` |
| `0x80482f6` | `sys_pipe` / suite fork + XOR blob `.crypt` |
| `0x80484d5` | fail password |

```text
(gdb) break *0x804828c
(gdb) break *0x804829a
(gdb) run
# saisir bruceschneier
(gdb) print/d $eax           # 13 si OK
(gdb) continue
(gdb) print/x $eax           # 0 si charset OK (@0x804829a test)
(gdb) continue               # → correct password! / secret code: …
```

```bash
gdb -nx -batch -ex 'set debuginfod enabled off' -ex 'file ./original/staple' \
```
