- Bad: "Nice try HAHAHA loser"

## Prédicat
```
serial = Asc(StrReverse(username)[0]) XOR CInt(ZastitaArray(1))
       = Asc(username[-1]) XOR key
```

Zastita (`sub_110031D0` / RC5-like + Rnd) reseed avec GetTickCount à chaque clic
→ key non stable sur le PE stock.

## Graine fixe (solveur)
- Patch stub GetTickCount @ 0x110020F8 : `mov eax, 0x12345678; ret`
- key observée (dump mem après FpI4) : **0x2AA192C8**
- petik → 107 XOR key = **715231907**
